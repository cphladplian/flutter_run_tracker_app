## 🏃 Run Tracker App

A Flutter mobile application for tracking running activities, integrated with Supabase as the backend service.

## 📱 Features

- Add running records (location, distance, number of people)
- View all running records in a list
- Update running information
- Delete running records with confirmation dialog
- Auto refresh after CRUD operations
- Splash screen on app launch
- Clean and simple UI

## 🧰 Tech Stack
- Flutter
- Dart
- Supabase
- Google Fonts

## 🚀 How to Run
git clone https://github.com/your-username/flutter_run_tracker_app.git
- flutter pub get
- flutter run

## ⚙️ Supabase Setup
1. Create a project on Supabase
2. Create a table `run_tb`
3. Add your Supabase URL & API Key in Flutter
